Entitlement carry runs on land only. The building is not financed until construction starts.

Construction carry uses the average drawn balance. The loan funds in over 18 months, so on average half is outstanding.

## 3. Stabilized operations

| Line | Basis | Annual |
|---|---|---:|
| Gross potential rent | 40 × $2,450 × 12 | $1,176,000 |
| Inclusionary zoning discount | 4 units × ($2,450 − $1,550) × 12 | −$43,200 |
| Other income | +3% | +$33,984 |
| Vacancy and credit loss | −7% | −$81,675 |
| **Effective gross income** | | **$1,085,109** |
| Operating expenses | $9,500 / unit | −$380,000 |
| Property tax | 0.85% of value | −$98,253 |
| **Net operating income (NOI)** | | **$606,856** |

Expense ratio 44 percent of income.

Tax is circular. It is charged on value, and value depends on NOI after tax. Solved directly:

> NOI = (EGI − opex) ÷ (1 + tax rate ÷ cap rate)
> = $705,109 ÷ 1.162 = $606,856

## 4. Value and return

> Value = NOI ÷ cap rate = $606,856 ÷ 5.25% = **$11,559,166**
>
> Value − cost = **−$4,769,124**
>
> Return on cost = NOI ÷ cost = **3.72%**
>
> Hurdle = cap rate + developer spread = 5.25% + 1.25% = **6.50%**
>
> Gap = **278 bps**

The spread is the premium for construction and lease-up risk over buying a finished asset at the cap rate.

## 5. Lever attribution

Each lever run alone against base. The package runs all zoning reforms together.

| Lever | Return on cost | Change | Share of gap |
|---|---:|---:|---:|
| Base | 3.72% | | |
| Entitlement 14 → 4 months | 3.75% | +4 bps | 1% |
| No parking minimum | 3.93% | +21 bps | 8% |
| No inclusionary set-aside | 3.93% | +22 bps | 8% |
| **Full zoning package** | **4.37%** | **+66 bps** | **24%** |
| Property tax to zero | 4.32% | +60 bps | 22% |
| Rent +10% | 4.25% | +53 bps | 19% |

Components do not sum to the package. Levers interact.

Entitlement is the weakest lever by an order of magnitude. Ten months of carry on $2.4 million of land is $160,000, or 1 percent of cost.

Under the full zoning package, residual land value is still **−$1.48 million**. The deal fails at any land price, so land drops out of the argument.
